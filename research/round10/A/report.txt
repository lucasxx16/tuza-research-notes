THEOREM (source-stated scope)
Theorem 1: every finite simple graph G satisfies tau(G) <= (165/59) nu(G).
Universal; constant 165/59 ~ 2.797 below Haxell's 66/23 and below Yi's
(162+4sqrt3)/59 route barrier 54/19 ~ 2.842. No factor-2 or mad<8 statement
follows from this theorem alone.

SECTION 2 — EXACT ASSUMPTIONS (source-stated)
- Graphs finite and simple; a triangle is its 3-edge set; triangles "meet"
  if they share an edge. Packing = pairwise edge-disjoint members; maximal
  and maximum packings as usual (maximum => maximal).
- F(H) = family of ALL triangles of the red/blue edge-colored H with exactly
  one red edge. Completeness (all such triangles) is essential: Lemma 2.1's
  exchange replaces uvx by uxy+uvz using that uxy in F(H).
- For P a packing: R(P),B(P) = red/blue edges of its members;
  F_P = F(H - B(P)) = one-red-edge triangles surviving deletion of B(P).
  If P is maximum, every member of F_P has its red edge in R(P), meets E(P)
  exactly in its red edge, and meets exactly one member of P.
- "private" edge = contained in exactly one family member.
- Lemma 2.1 (exchange): P maximum in F(H), uvx in P red edge uv, uvy in F_P.
  If xy is a red edge outside R(P), then uv is private in F_P.
- Lemma 2.2 (books): books of <=3 pages, pairwise edge-disjoint supports;
  every selection of one page per book is a MAXIMAL packing in T. Then C
  (edges of one-page books + spines) plus opposite edges of two-page books
  is a transversal of T of size <= sum_B (4-|B|).
- Lemma 2.3: P maximum in F(H), Q maximum in F_P, p=|P|, q=|Q|,
  u = #members of P with a red edge private in F(H). Then
  (1) tau(F) <= (8/3)p - (2/3)u ;
  (2) tau(F) <= (9/4)p + (3/2)q - (1/4)u.  [u = "private" shaving terms]

SECTION 3 — VARIABLES AND INEQUALITIES (source-stated)
- P max triangle packing in G; n=|P|=nu(G); O=E(P)=old edges; no type-0
  triangles by maximality. Type j = contains exactly j old edges.
- A max packing of type-1 triangles; a=|A|. Books P+A:
  (3) tau(G) <= 3n - a.
- G' = G - E(A), O' = O\E(A), |O'| = 3n-a; new edges red, old blue in G';
  F(G') = F_2 (type-2 triangles).
- P' packing in G' maximizing first #type-2 then size m; B* = its type-2
  members, b=|B*|; R(B*)=N, |N|=b. Source-stated relation: a + m <= n.
- S = F(G' - B(P')) (type-2 triangles with old edges avoiding E(P')); B*
  maximum in F_2; Q maximum packing in S; c=|Q|; h = #members of Q with a
  red edge private in S.
  Books B*/Q + random bit bipartition:
  (4) tau(G) <= (3/2)n + (5/2)a + (3/2)b - c + (3/8)h.
- Q1 max packing in S_Q = F(G' - B(P') - B(Q)); d=|Q1|. Third-page books:
  (5) tau(G) <= 3n - c - d.
- Lemma 2.3 on G'-B(P') (Q,Q1,c,d,h in roles P,Q,p,q,u), eq (2):
  (6) tau(G) <= 3n - b + (9/4)c + (3/2)d - (1/4)h.

COMBINATION (baseline, already known — not new here)
Weights 20:8:19:12 on (3),(4),(5),(6); coefficients of a,b,c,h cancel:
  59 tau(G) <= 165 n - d <= 165 nu(G).  [known]

KNOWN EQUALITY PARAMETER POINT (from paper Remark)
a = c = 12n/59, b = m = 39n/59, d = h = 0: all four right-hand sides equal
165n/59. Remark states these weights are best possible for equations (3)-(6)
under the parameter constraints used in the proof. The tuple is an abstract
feasible point, not a claimed realizable graph.

CONSTRAINTS EXPLICITLY LISTED IN THE REMARK'S DOMAIN
The Remark lists a+m <= n, d <= c <= b <= m, h <= c as relations used
for its four-inequality optimality witness. The cited passages do not
provide a universal d+h lower bound. This is a bounded reading claim,
not an assertion that the full source has no other implicit structural
relation. Re-weighting/LP on the same four inequalities under only
this displayed domain cannot beat 165/59 (known fixed-system barrier,
research/round10/C); a true route needs a new valid constraint, a
strengthened inequality, or a different global argument.
