ROUND 8 C — TRIANGLE PLUS ISOLATE PRELIMINARY ADVERSARIAL REVIEW

Let core be triangle T={p,q,r} and isolate s. The forthcoming proof does not use a core perfect matching. In one connected non-WKE link, each private has at least two neighbors in T. If b misses p,q, set Q={z,a,r}; outside Q only pq and optional sb remain. The three exhaustive matching choices are {pq,sb,zr} if sb exists; {pq,br,zs} if sb absent and br exists; and {pq,ab,zs} if sb,br absent, when connectivity forces ab. Each has size three, includes all outside-Q edges, and contradicts non-WKE. This even forbids two triangle vertices with the same singleton private column.

Every core vertex, including isolate s, must have a private neighbor. If t unsupported, set Q=C\{t}; outside Q only zt and optional ab remain. When ab exists, add a triangle edge avoiding t to {zt,ab}. When ab is absent, both private vertices have at least two triangle neighbors, all avoiding t; choose distinct representatives and add their attachment edges to zt. These are exact three-edge WKE witnesses.

For each side, three nonempty triangle columns and ≥2 triangle neighbors per private imply at least one doubled triangle vertex. A2 forbids a vertex doubled on both sides, so among the disjoint nonempty double sets one side has exactly one; after relabeling its columns are {a},{b},{a,b}. For any triangle vertex i, the other two columns admit distinct private attachments with one crossed attachment absent: if i is the double, use the two singleton columns; otherwise use the remaining singleton and double. If an opposite-side private differs between i and s, O1 applies after hub exchange, with c1/c3 the seen/missed pair (i,s) and c0/c2 the remaining triangle edge. Thus if O1 never applies, each opposite-side private is constant across all triangle points and s, making the three triangle columns a common nonempty set. A singleton common set violates the ≥2-neighbor lemma for the other private; a double common set violates A2 at the first side's doubled vertex. This is an exhaustive structural forcing of O1, pending the literal final S/X mapping and ambient checks.
