## 1. Object under test (premises imposed by the parent, not derived)
H finite simple, every edge red/blue, EVERY triangle of H has EXACTLY ONE red edge.
  p          = max number of pairwise EDGE-disjoint triangles of H (exact, with witness)
  p_private  = max number of pairwise edge-disjoint triangles whose red edge lies in
               exactly ONE triangle of H (globally private red edge)
  premise    = p_private == p > 0. This is equivalent to "there is a MAXIMUM packing Q
               whose red edges are globally private": private packings are a subfamily,
               so p_private <= p always, and equality means some maximum packing is
               private-only. Q is returned and re-checked literally (length, disjointness,
               privacy of each red edge).
  tau        = min number of graph EDGES meeting every triangle (Tuza EDGE transversal,
               exact, with witness). NOT a vertex cover — round10's first run did that and
               is withdrawn.
  r          = #red edges lying in >= 1 triangle.   premise r <= 3p
  s          = #participating red edges lying in >= 2 triangles ("multipage" red edges).
               s = 0 means every triangle's red edge is globally private.
Witness test:  100*tau > 199*p  (equivalently tau/p > 1.99), reported with the exact
               integer margin 100*tau - 199*p. In stage 2 this is a BUG ALARM ONLY (4b):
               for an eligible instance at n <= 12 it can never fire, so a firing record
               is treated as a solver/record defect, not as a witness to anything.
               Sanity invariants recomputed per instance: p <= tau <= 3p, and under the
               private premise tau <= 2p - 1 (Role E, C-approved); violations reported.

## 2. Engines (deliberately doubled, no shared code path)
A. AUDITED round10 engine, imported read-only:
   research/round10/B/red_budget/red_edge_search.py  (R10.analyse / R10.dump /
   R10.tri_masks / R10.max_packing / R10.edge_cover). Graph-EDGE bitmasks, exact branch
   and bound with witness reconstruction; premise gate = every-triangle-one-red, p>0,
   p_private==p, r<=3p, connected. Only the imported module's NODE_CAP
   global is reassigned (250000). Historical round10 files are NOT modified: mtimes and sizes of every .py/.json/.txt in
   that directory are snapshotted before/after every stage-1 run and reported as
   `round10_untouched` (the byte-compile cache red_budget/__pycache__/*.pyc is outside that
   snapshot; its mtime 17:33:32 predates every stage-1 run of this session).
   Any instance whose p, p_private or tau is not certified inside the node cap is SKIPPED
   and counted as an UNCERTIFIED SKIP under its exact reason string — R10.analyse returns
   packing_not_exact / private_packing_not_exact / cover_not_exact (plus this file's own
   not_exact_nodecap, solver_engine_error); these live in the UNCERTIFIED list at the top of
   targeted_search.py and are NEVER counted as premise rejections (premise rejections go to
   premise_rejects: no_triangle, not_exactly_one_red, nu_zero, private_premise_fails,
   r_gt_3nu, disconnected). No uncertified instance is ever assigned a guessed value, and
   no uncertified instance is counted eligible or retained.
B. STANDALONE literal verifier: research/round11/B/verify_witness.py. It imports nothing
   from round10 or from targeted_search.py. It re-parses the colorstring, re-enumerates
   every triangle, re-checks every triangle constraint, and re-derives p, p_private, tau,
   r, s with its own two methods:
     * exhaustive subset enumeration (bitmask DP over subsets of triangles, and over
       subsets of candidate edges) — exact by construction, used when 2^k <= 1<<20;
     * scipy.optimize.milp (HiGHS) integer program, ACCEPTED ONLY if status == 0
       (Optimized), the solution is integral to 1e-6, and the decoded set passes the
       literal disjointness / hitting re-check.
   When both run they must agree; disagreement => not certified (methods field
   `brute+ilp_agree=False`). An LP/relaxation value, an incumbent without optimality
   status, or a timeout is never read as an exact optimum. Engine B is time-BOUNDED: every
   scipy.milp call gets options={'time_limit': max(0.01, shared_absolute_deadline - now)},
   recalculated by verify_witness._opts before each solve (a bare CLI verifier run uses the
   solver default). A HiGHS time-limit stop returns status != 0 and yields no value: the
   instance either falls back to exact brute enumeration ("brute_only") or is reported NOT
   CERTIFIED. Before an instance may be counted eligible or retained, targeted_search
   requires ALL of: B certified, B eligible (its own premise re-check), B's p_private equal
   to A's, every B literal-check flag True, B's every-triangle-one-red constraint True, no
   claim mismatch (claims now include p_private), and A-vs-B agreement of the per-red-edge
   page counts (A nonprivate_red vs B nonprivate_red_edges). Any failure lands in
   `disagreements` with both values printed, never in the eligible count.
Every retained stage-2 example must have A and B agreeing on p, p_private, tau, r, s;
disagreements are logged and the instance is dropped. K4 is a rejection control:
engine A exits at the private-premise gate, so only B certifies its global quantities.

## 4. Stage 2 generator plan (implemented in targeted_search.py, awaiting C's audit)
Why the round10 randoms were weak: 899 eligible occurrences, all with tau = p. iid sparse
graphs almost never put a red edge into two triangles while still leaving a private
maximum packing, so s > 0 essentially never occurred. Stage 2 therefore starts from
structured seeds and mutates them.
  seeds (all n-aware; unused vertices are attached, never left isolated):
    cone_odd_cycle / cone_C5 / cone_C7 / cone_C3 : C_k RED base (k odd) + BLUE apex.
       Every cone instance examined so far had all red edges private (s=0) and the best cone
        ratio on record is the 3/2 of the C5 control above. No cap of the cone family is
        asserted in code or used as a premise; the run reports computed numbers only.
    two_cones_linked : two odd-cycle red cones on disjoint bases joined by a
       triangle-free bridge (a matching / shift between the bases) — keeps the base edges
       private while coupling packings across the two apices.
    book_pages_red / book_spines_red : books on vertex 0; red on page edges (private) vs
       red on the spine edge (spine becomes multipage, premise outcome recorded per instance) — the
       two poles of the privacy trade-off; whether the premise survives is recorded per
       instance, not assumed.
    spine8_c4_plus_path : the required s>0 control above, reused as a STRUCTURAL SEED for
       n >= 9 (n = 9..12 only, padding attaches the extra vertices). Candidate extension
       for a later round: two spine8 blocks sharing ONLY the red edge (0,2) (Role E's
       H_(k,t) family) needs n = 16 at t = 2, which is OUTSIDE the agreed 6..12 order cap;
       it is NOT added and will not be run unless the coordinator explicitly raises the cap.
  mutations of VALID parents (intermediate states may break a premise; they are rejected
  and counted, which is the intended "slightly relaxed" walk): flip edge presence,
  recolor an edge, add a page on an existing RED edge (raises s), grow a triangle on a
  BLUE edge with one new red edge (adds a private triangle), drop an edge, add a
  triangle-free bridge edge. 60% of iterations mutate an eligible parent from the pool,
  40% redraw a structured seed; n in 6..12, prioritising s > 0 and high tau/p. The order n is
   fixed BEFORE any mutation (parents are drawn only from orders whose quota is unspent and
   the per-n quota is charged on that final n), so a mutation can never move an instance
   into an already-saturated order; when every order's quota is spent the loop STOPS with
   `per-n eligible quotas saturated` — there is no `or NS` fallback quietly resuming
   saturated orders, so the per-n caps are as hard as the global 1000-eligible cap.
  dedup: exact labeled colorstring (no isomorphism reduction); repeated labeled colorings
  are counted in `repeats` and reported separately (`repeat_counts_top`).
  retention: top 40 per stratum (s == 0 / s > 0), sorted by (-tau/p, p). Each record carries
  p, p_private, tau, r, s, the max packing Q, the minimum EDGE cover, the per-non-private-
  red-edge page counts and max_red_pages, tau/p, the value 2p-1 plus the gap to it, and the
   margin 100tau-199p. The witness test is demoted to a BUG ALARM (`witness_alarm`, which
   must stay empty — see 4b); no small example is reported as an RB(1/100) witness.

## 4b. Stage-2 objective RETARGETED after round-11 C (citing Role E, C-approved)
Role E's C-approved statement: every full one-red colouring H with an all-private maximum
packing Q satisfies tau <= 2p - 1. A strict RB(1/100) counterexample would need
1.99p < 2p - 1, i.e. p > 100. EXACT REASON small orders cannot refute RB(1/100): at
n <= 12 the graph has at most C(12,2) = 66 edges and p edge-disjoint triangles use 3p
distinct edges, so p <= 22 < 101 — no n <= 12 eligible instance can have tau > 199p/100.
Stage 2 is therefore a HARD-INSTANCE DIAGNOSTIC, not a witness hunt: find eligible
instances with s > 0 and tau/p as high as possible (target > 1.5, the C5-cone level),
validate the bounded quantities (p, p_private, tau, r, s, red-edge page counts) against the
independent solver B, and report the gap to the 2p-1 ceiling. No claim is made that any
retained small example has witness value for RB(1/100). Graph orders stay 6..12 and the
budgets below are unchanged. The full Role E source is forthcoming; nothing in this
protocol re-derives or proves that bound.

## 5. Stage 2 budgets (soft 180 s process target; no OS-enforced kill)
The deadline guards and per-solve time limits aim to stop within 180 s, but Python
and solver overhead may overrun. The result must report actual elapsed time:
  SELF_LIMIT_S   150  — check_deadline() raises at each loop iteration before a draw;
                        engine B's per-solve option uses the shared absolute deadline;
  WRITE_DEADLINE 168  — check_write_slot() must pass before any artifact is written; if the
                        deadline passed, the run prints its summary and records
                        `artifact_written: null` + "WRITE SKIPPED" instead of blowing the wall;
  SOLVE_SLACK      3  — reserved after the last possible solve for bookkeeping/writing;
  engine A         — R10.NODE_CAP = 250000 branch-and-bound nodes per exact solve;
  engine B         — brute subset cap 1<<20 per subproblem AND scipy.milp
                     options={'time_limit': remaining wall before the shared absolute
                     deadline}, recalculated by _opts before each solve; a time-limited
                     status is never a value;
  draw caps        — <= 10000 generated colourings, <= 1000 eligible inputs overall,
                     per-n eligible quota ~142 checked on the FINAL n (no fallback orders).
Counters (separate buckets, never conflated): attempts, unique, repeats, eligible,
premise_rejects{reason}, uncertified_skips + uncertified_reasons{reason},
engine_b_not_certified, disagreements, gen_unusable, parent_mutations, witness_alarm,
hist_tau_over_p, hist_s, hist_max_red_pages, per_n{attempts,eligible,quota}. No download,
no re-run of the original 1144-census, no LP bound used as an optimum.
