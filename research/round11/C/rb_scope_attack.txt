ROUND 11 C — FIRST ADVERSARIAL RB AUDIT

Target RB(epsilon): every finite simple red-blue H whose EVERY triangle has exactly one red edge, with participating red count r≤3p and SOME maximum p-triangle packing whose red edges are globally private, has tau(H)≤(2−epsilon)p. No counterexample or proof is established in this note.

An exact auxiliary reformulation identifies the unresolved mechanism. Make J's vertices the blue edges of H and one J edge per H triangle, joining its two blue edges. J is triangle-free: three pairwise intersecting blue edges would be a blue triangle or a blue star with red edges among all three leaves, both forbidden by the one-red condition. Color each J edge by the corresponding red edge of H. Each color class is a matching because distinct pages on one red spine xy use disjoint blue-edge pairs xz,yz. H packings correspond exactly to rainbow matchings in this edge-colored J: shared blue edge is shared J endpoint; shared red edge is repeated J color. H edge transversals correspond exactly to mixed covers choosing J vertices (blue edges) and/or colors (red edges). The number of used colors is r. Q-private means some maximum rainbow matching consists of singleton color classes.

When ALL used colors are singleton, ordinary matching/vertex-cover in triangle-free J gives the accepted 9/5 bound at r≤3p. RB only assumes Q's colors are singleton. For an arbitrary properly colored triangle-free J, this weaker condition does NOT force ordinary matching number to equal maximum rainbow-matching number: take the six-vertex path with edge colors, in path order, b,c,a,d,b. Its unique three-edge perfect matching uses color b twice, so ordinary matching number is 3, while the singleton-color edges c and d form a maximum rainbow matching of size 2. The H-realizable counterexample below shows the same gap within RB's full hypotheses. A proof must account for both color-repeat restrictions on packing and color choices in covers. Maximum cannot be weakened to maximal, and a private edge of Q is private in the full triangle family, not merely in Q.

More precisely, realizable J lies in the line graph of the BLUE subgraph of H: adjacent J vertices represent incident blue edges. For a red spine xy, its color class contains ALL blue two-edge paths x-z-y present in H, because each closes to a one-red triangle. These closure constraints are stronger than “J triangle-free with matching color classes.” Both the red and blue subgraphs of H are triangle-free. This is why an abstract colored-J obstruction alone would not settle RB.

CORRECTION / REALIZABLE COUNTEREXAMPLE TO mu(J)=p. E supplied and I independently checked the following family. For k≥4 take a blue cycle x0 x1 ... x_(2k−1) x0 and blue edges yx0,yx2. Take red edges forming the even-vertex k-cycle x0 x2 ... x_(2k−2) x0 and the odd-vertex path x1 x3 ... x_(2k−1) y. Every H triangle has one red edge. The J vertices, in path order, are blue cycle edges E0,...,E_(2k−1), then F0=yx0,F2=yx2. J is exactly that (2k+2)-vertex path. Its first and last edges have the SAME red color x0x2; every middle edge has a singleton color. The unique ordinary perfect matching has k+1 edges and repeats x0x2, whereas a maximum rainbow matching Q of k singleton-color edges exists. Thus p=k, mu(J)=k+1, r=2k≤3p, and tau(H)=k+1 (ordinary vertex-cover k+1; selecting the one repeated color still leaves an internal path requiring k more cover elements). For k=4 the exact nine-vertex check found 9 H triangles, p=4, private-Q size4, r=8, mu(J)=5, tau(H)=5. This refutes the tempting equality mu(J)=p WITHIN the full RB hypothesis, but its cover ratio (k+1)/k is nowhere near two and does not refute RB itself.

Unbounded additive gap with only one nonprivate red color: take t copies of the preceding k-block, identify every x0 as one u and every x2 as one v, and keep all other vertices disjoint. There are no cross-block triangles because no other cross-block edge is added; the sole shared red spine is uv. J is t disjoint (2k+2)-vertex paths, all 2t endpoint edges sharing color uv. Each path has rainbow matching number k despite ordinary matching k+1, so p=kt and mu(J)=(k+1)t. The red count is r=1+(2k−1)t≤3p and only s=1 red color is nonprivate. Selecting uv plus k blue-edge vertices per path covers all triangles for kt+1; without uv, each path requires k+1 vertices, and singleton other colors can be replaced by vertices, so tau(H)=kt+1. Consequently mu(J)−p=t is unbounded with s fixed at 1. The cover ratio is still 1+1/(kt); this kills μ≤p+C·s, not RB.
