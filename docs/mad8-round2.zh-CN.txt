问题三第二阶段：从完全邻域推进到 K7 删匹配的全部邻域

结论：完整的 mad(G)<8 => tau(G)<=2nu(G) 仍未解决。本轮严格扩大了
上一轮可处理的七度顶点范围，并把最小反例的必要连通性加强到四连通。
结果经过独立代理攻击审查与协调者复核，不宣称首创性、人工同行评审
或形式化证明。本轮按阶段成果停下报告。

一、主线定理：允许七度邻域中出现不相交的缺边

定理 M：设 d(u)=7，且 G[N(u)] 是 K7 删去一组匹配得到的图。
对任意满足 d(v)<=8 的邻点 v，{u,v} 都是可约对。

也就是说，上一轮只允许完全邻域，本轮允许零、一、二或三条缺边，
只要求这些缺边两两不共端点。其他顶点的度数没有上界要求。

证明只使用三种明确的构造。下列三种情形均假定 uv 是边，
且 d(u)+d(v)<=15；共同邻域记为 C。

  A. C 含 K5：七个边不交三角形，至多十四条覆盖边。
  B. C 含诱导 C4，且还有第五个共同邻点：五个三角形，至多十条覆盖边。
  C. C 中五点诱导 K5-xy，另有 u 的邻点 w 在这五点及 v 之外，
     且 wx 是边：修补一个 Fano 三角形，得到七个三角形和至多十四条边。

三种构造都覆盖所有经过 u 或 v 的三角形，并将每条不接触 u,v 的
打包边放入覆盖集。这保证它们可以用于递归归约。
B 中“诱导”不能删去；四边形若有对角线，当前证书会漏掉三角形。

若 v 不接触邻域中的缺边，公共邻域是 K6 删匹配，由 A 或 B 处理。
若 v 接触一条缺边，公共邻域是 K5 删去零、一或两条匹配边，
分别由 A、C、B 处理。由此穷尽全部匹配类型，无须枚举图目录。

二、由局部定理得到的条件密度界

设 G 非空、最小度至少七，L 为全部七度顶点。若每个七度邻域的
补图都是匹配，且 L 的所有邻点度数至少九，则

    2|E(G)|/|V(G)| >= 8 + 3|L|/(4|V(G)|)。

证明中，每个七度顶点向七个邻点各收取 1/4，最终电荷为 35/4。
与 L 相邻的 d 度顶点至少有五个非七度邻点，最多支付 (d-5)/4，
剩余至少 (3d+5)/4 >= 8。八度顶点不与 L 相邻，保留电荷八。
求和得到上述不等式；不主张这个界尖锐。

因此：最小度至少七、平均度小于八，并且每个七度邻域的补图都是
匹配时，必有定理 M 的显式可约对。

这个结论仍是强制可约配置的定理。邻域补图为匹配的性质未必在删边
后保持，不能据此直接宣称已证明整个附加条件图类的 Tuza 猜想。
但它可以排除具有这些局部性质的子图最小反例。

完整证明：mad8/round2/E/matching_complement_links.txt。

三、独立路线：最小反例必须四连通

若图沿至多三个顶点分成两侧，且两侧及删除任意公共边后的图都满足
Tuza 不等式，则整个图也满足。证明比较恢复公共边前后的最大打包
增量，并据此选择覆盖；共享三角形的情形也得到完整处理。

所以，在任何对子图封闭的图类中，按 |V|+|E| 最小的 Tuza 反例
若存在，必为四连通。mad<8 对子图封闭，故适用。

还得到一个进一步的必要条件：若这样的最小反例有四顶点割集，
割集内部至多三条边，那么内部图只能是 P4 或 K1,3，且切开的两侧
必须满足明确而不对称的打包增量和覆盖紧性条件。尚未证明这些剩余
模式不可能出现，也不把它们称为反例。

完整证明：mad8/round2/D/three_edge_boundary.txt。

四、核验、被驳回的计算及下一步

通用结论来自上面的完整论证。计算仅核验两个已给出的具体证书：
诱导四边形构造的五三角形/十覆盖边实例，以及修补 Fano 的七/十四实例。
复现命令：

  python mad8/round2/B/check_core_matching.py
  python mad8/round2/C/check_literal_C4.py
  python mad8/round2/B/check_repaired_fano.py

计算审查曾发现端点与核心标记混淆，导致一次单图优化输出无效；
另一个检查器把边当作顶点枚举，并错误检查打包成员而非覆盖集。
这些输出均被驳回。发布的检查器已修正并复核，不用求解器状态作证明。
原论文 census 和 certificate 搜索未重跑。

剩余缺口现在可更精确地表述为：一个最小反例必须含五/六度顶点，
或者含一个七度顶点，其邻域补图中有某个顶点的度数至少二。
本轮没有解决这两类情形。下一轮可优先研究后一类中最小的缺边结构，
同时检查它与五/六度顶点电荷需求的兼容性。

审查记录：mad8/round2/C/；协调者结论：mad8/round2/review_summary.txt。
